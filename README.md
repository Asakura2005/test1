# HAQ FOOD Landing Page

Landing Page giới thiệu và đặt mua các combo đồ ăn vặt cổ truyền & hiện đại của **CÔNG TY CỔ PHẦN HAQ HÀ NỘI** (Bánh Chả Phố Cổ, Bánh Tráng Sấy HOKI, Bắp Rang Bơ Nấm Caramel, Bò Sấy Khô Sợi, Bánh Đậu Xanh...).

## Công Nghệ Sử Dụng
- **React 18**
- **Vite 5**
- **Tailwind CSS 3**
- **Lucide React Icons**

## Cài Đặt & Chạy Thử
```bash
# Cài đặt dependencies
npm install

# Khởi chạy server phát triển
npm run dev

# Đóng gói sản phẩm (Production build)
npm run build
```

## Tính Năng Nổi Bật
- **Bộ lọc gu vị giác tương tác**: Bùi béo lá chanh, Cay giòn rụm, Ngọt bơ thơm ngậy.
- **Hồ sơ cảm quan món ăn**: Thang đo độ giòn 5/5, thành phần nguyên liệu và đồ uống đi kèm.
- **Gợi ý ẩm thực & Pairing**: Bánh chả & trà sen, Bánh tráng sấy & trà sữa, Bò khô & bia lạnh, Bắp caramel & xem phim.
- **Bài toán tiết kiệm Combo**: Tính toán trực quan số tiền tiết kiệm khi mua theo combo.
- **Quy chuẩn đóng gói Unboxing**: Thùng carton 5 lớp chống va đập, túi màng nhôm ép nhiệt kháng ẩm 9 tháng.
- **Form đặt hàng trực tuyến COD**: Tính tiền tự động, chính sách Freeship toàn quốc và quyền lợi ăn thử trước khi thanh toán.
